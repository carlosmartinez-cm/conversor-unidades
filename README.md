# Conversor de Unidades

## Descripción
Programa en C que permite convertir entre diferentes unidades de medida.  
Resuelve la necesidad de realizar conversiones rápidas de temperatura, longitud y peso desde la consola.

## Funcionalidades
- Conversión de Temperatura (Celsius, Fahrenheit, Kelvin)
- Conversión de Longitud (metros, kilómetros, millas, centímetros)
- Conversión de Peso (kilogramos, libras, gramos)

## Tecnologías utilizadas
- Lenguaje: C
- Librería: stdio.h

## Cómo compilar y ejecutar

### Requisitos
- Compilador de C (gcc, MinGW, o Visual Studio)

### Compilación
```bash
gcc main.c -o conversor_unidades
```

### Ejecución
```bash
./conversor_unidades
```

En Windows:
```bash
conversor_unidades.exe
```
